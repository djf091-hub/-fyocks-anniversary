FYOCKS Anniversary Website
==========================
Unique original JPEGs included: 101
Exact duplicate uploads excluded: 20

HOW TO USE
1. Unzip the folder.
2. Keep index.html, style.css, app.js, photos.js, and the photos folder together.
3. Upload the entire folder contents to your website host.
4. Open index.html.

IMPORTANT
- The JPEG files in /photos are byte-for-byte copies of the user's uploaded originals.
- No AI image generation, facial modification, retouching, cropping of source files, or recompression was performed.
- CSS uses object-fit: cover only for the small animated tiles. Tapping a tile displays the complete original image with object-fit: contain.
- Duplicate removal was based only on identical SHA-256 file contents.
